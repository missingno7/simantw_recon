# Near-exact lane brief (per-agent, disjoint target lists)

You work in `D:\Prog\simantw_recon` (run every command from there with `python`). Read `docs/sonnet-grinder-brief.md` first and obey all of its hard rules (never edit `tools/`, `layout/`, `src/`, `evidence/`, `build/recovered/`, `docs/`; never run promote/refresh/handoff_validate/git; never `grind.py next`). This brief adds the lane-specific method.

Your targets are already **>= 95% opcode-exact** under the correct object profile. Their jobs were reopened with a recorded 4-attempt extension. The residual is a *single idiom*, so do not rewrite control flow and do not re-derive semantics from scratch.

Start from the fresh best candidate: `evidence/recovery/near-exact-lane.json` lists for each target `source` (the best preserved candidate, compiled under the current profile), `family`, `residual` (the aligned-asm rows that still differ) and `wrong_bindings` (fixups the matcher resolved to a wrong displacement). Copy that source into `build/grind/<agent>/SYMBOL.c` (CRLF), then change only what the family suggests:

- **FRAME** (only `stack_local_layout` differences): the compiler gives frame slots to locals in a definite order. Try, one at a time: swap the declaration order of the locals involved; merge/split declarations (`int a, b;` vs two lines); change a local's width (`int`/`char`/`long`/`unsigned`); make a value a named local instead of a repeated subexpression or the reverse (CSE temporaries under `/Og` get frame homes *below* declared locals — do not declare a local for a value the original recomputes); take the address of a local (`&x`) only if the target shows the slot is written through a pointer; move a local into a nested block scope. Keep the opcode sequence unchanged; compare `stack_local_differences` after each attempt.
- **REGISTER** (only `register_allocation` differences): which value lives in SI/DI. Try: copy a parameter into a local at the top of the function (or stop doing so), reorder the first uses of two variables, `unsigned` vs `int` for a loop counter, an explicit result variable for `MOV DX,...` tails, splitting one expression into two statements.
- **BRANCH**: `if (a) … else …` vs early `return`; `goto` to a shared tail vs duplicated tail; `while` vs `do/while` vs `for`; `!=` vs `==` polarity; `switch` case order.
- **BINDING** (`wrong_bindings` non-empty; opcodes exact): the source addresses the wrong object or index. Look at `wrong_bindings[].symbol` (what the candidate referenced) and `resolved` (the address the original literal really means). Use MAPSYM names via `grind.py inspect` (`direct_data_bindings`, `exact_mapsym_names`) and the admitted neighbours in `src/recovered/` to find the object that actually lives at the resolved address and its element width; fix the declaration or index expression. Never keep a displacement that the matcher says resolves elsewhere.
- **NEAR_SHAPE** (1-2 opcode differences): read the `residual` rows; the extra/missing instruction names the idiom (a `mov` vs an in-place `add`, `cwd` from a signed operand, a bounds check the target folds, `inc` vs `add 1`, a `test` vs `cmp 0`, a value kept in a register across a call).

Siblings: when the lane lists `siblings` (same object, same size, same family), solve one and apply the same edit to the sibling immediately.

Use `python tools/grind.py test SYMBOL build/grind/<agent>/SYMBOL.c` for each attempt (4 attempts per target in this lane, budget is recorded), then `accept` when the strict result is CONFIRMED/STRONGLY_SUPPORTED, or stop when the automatic BODY_MATCHED_BINDING_BLOCKED escalation fires (that is success: the supervisor admits it through a scaffolded unit). If accept fails with "not an immutable exact tested candidate", convert the file to CRLF, re-run test, accept. When the four attempts are spent without exactness, `grind.py block SYMBOL "<the residual and every variant tried>" --cause <REGISTER_ALLOCATION|LOCAL_FRAME_LAYOUT|EXPRESSION_SHAPE> --next-experiment "<one idea>"`.

Report at the end: symbol, result, attempts, the idiom that fixed it (one line) or the residual that remained. The fixing idiom matters more than the count: it will be propagated to other members of the same object.
